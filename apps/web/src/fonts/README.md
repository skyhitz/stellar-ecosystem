# Fonts

Self-hosted so the app makes no requests to a font CDN.

| File | Family | Weights | Licence |
| --- | --- | --- | --- |
| `jetbrains-mono-latin-wght-normal.woff2` | JetBrains Mono (variable, Latin subset) | 100–800 | SIL OFL 1.1, see `JetBrainsMono-OFL.txt` |
| `unbounded-latin-wght-normal.woff2` | Unbounded (variable, Latin subset) | 200–900 | SIL OFL 1.1, see `Unbounded-OFL.txt` |

Both files come unmodified from the `@fontsource-variable/jetbrains-mono` and
`@fontsource-variable/unbounded` packages, version 5.3.0, which mirror the
Google Fonts builds. To update, copy the same two files from a newer release.
